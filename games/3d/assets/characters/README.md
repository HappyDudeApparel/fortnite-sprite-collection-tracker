# Characters for Sprite Arena (3D)

- `citrus.glb` — recovered from `gamer-bros-game/pass1-v1/assets/recovered/characters/sprite_hero.glb` (the Citrus / Dash model). Rigged; clips: Idle, Walk, Jump, Dance, HitRecieve, Bite_InPlace.
- `ghost.glb`, `yeti.glb`, `stump.glb`, `cthulhu.glb`, `alien.glb` — recovered rigged monsters (from `hero.glb`, renamed `alien`). **Original author / licence is not recorded in the repo** — confirm before any public release.
- To add another playable 3D Sprite later, drop a rigged `.glb` here and add it to `js/roster.js`; clips named Idle / Walk / Jump / Bite_InPlace are picked up automatically.
