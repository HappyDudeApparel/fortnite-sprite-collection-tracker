# Sprite Collection Locker v2.0.15 — C7S4 Launch

## Deploy
1. Open the GitHub repository used by sprites.happydude.ca.
2. Replace the repository-root files with the contents of the GitHub-root ZIP.
3. Keep the files at the repository root; do not upload the ZIP itself and do not create a version subfolder.
4. Commit the replacements to the publishing branch.
5. After GitHub Pages deploys, open https://sprites.happydude.ca/ and hard-refresh/relaunch the installed PWA if needed.
