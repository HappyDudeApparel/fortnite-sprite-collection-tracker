# Sprite Collection Locker — Phase 3 acceptance and regression audit
**Authority:** Owner-approved November 1 `LOCKER_APPROVED_MAIN_PAGE.png` and `LOCKER_APPROVED_FEATURED_AND_BACKGROUNDS.png`. These are concept art; pictured mock characters, counts and browser chrome are **not** authentic game data.
**Status:** Release-blocking audit conducted on unpublished branch `feature/locker-approved-scroll-2026-11-10`; final expanded browser workflow outcome to be appended below. No production publication is authorized in this phase.

## Scope and method
- Visual side-by-side comparison: approved images versus real browser screenshots at **320, 360, 390, 430, 768, 1024 and 1440** CSS pixels. Checks include hierarchy, architectural image, live Llama projection, cyan/gold/violet card borders, in-frame gallery scrolling, text readability, variant ribbon, Featured Sprite, current background and carousel position.
- Functional: native search, owned/missing filters, list/grid, accessible scrolling, family and variant selection, scene image binding, all 58 background buttons, selected-background visibility, actual PNG image generation/Save button invocation, native ownership and mastery, reload persistence, C7S3/C7S4/C7S5 navigation and JavaScript exceptions.
- Static data: compare complete `SPRITES` and `BACKGROUNDS` arrays **exactly** against `main` (not approximate). Strip the four additive Locker CSS/JS links and compare `index.html` byte-for-byte to `main`. Decode local artwork with Pillow. All test state occurs in disposable Chromium browser profiles.

## Findings and corrections
**F3-01 — Artwork duplicated sample navigation (FIXED).** The baked-in first 27–28 px from the approved-derived vault illustration rendered a decorative extra row of navigation immediately below the real site header. Both the 1764px-wide mobile and 2200px-wide desktop source images were surgically cropped and re-encoded at the same source dimensions. Real navigation remains interactive and unaffected.

**F3-02 — Cross-season Locker selection reset after reload (FIXED).** The canonical application boots to C7S5 and normalizes `selectedId` to the active-season roster, which can override a saved C7S3/C7S4 selected Sprite in memory. A **Locker-tab-only capture handler** in `assets/ui/locker-phase2.js` restores the valid persisted sprite ID just before rendering Locker. Original season nav and source code are untouched.

**F3-03 — Image Save / Share needed stronger verification (TEST EXPANDED).** Earlier tests checked only the export dialog. The new audit checks creation of a nonempty **1600 × 1200 PNG Blob**, native Save action invoking an anchor with a blob URL and PNG filename, and decodes generated bytes as an actual image. Headless CI may suppress the operating-system download manager event; do not report a real user download as tested solely from Playwright's native download event. The on-device share sheet must be checked on staging during Phase 4.

**F3-04 — Background carousel and persistence (TEST EXPANDED).** Tests now cover the last of 58 genuine source backgrounds, its visible selected thumbnail, live feature background synchronization and remembered index after a full page reload. The browse arrows remain separate from actual selection.

**F3-05 — C7S4 external images (KNOWN DEPENDENCY, NOT EDITED).** 293 Sprite paths are local, decodable assets; the remaining **23 are C7S4 Trick-or-Treat portrait URLs hosted at `fortnite.gg`**. Their external reachability and offline use cannot be established by local-file tests. They have deliberately not been replaced, rewritten or silently marked invalid. This inherited production dependency is an explicit release consideration.

**F3-06 — PWA update delivery (PHASE 4 PUBLISH CHECK).** Production version/cache invalidation and real hosting verification should be handled in the staging-and-publication phase; Phase 3 must not update production or silently merge this branch.

## Source invariants
- 316 unique Sprite IDs: C7S3 **119**, C7S4 **162**, C7S5 **35**; **67 base families**.
- **58 genuine in-app backgrounds**.
- The original `index.html` is exactly equal to `main` after removing its 4 extra Locker-only asset references. Both protected data arrays compare exactly to `main` in CI.
- **10 extracted Phase 1 visual asset files** and 293 local Sprite portrait files pass image format/decodability checks.
- User-critical John Wick, Ironmouse, Pollo, Vini Jr, Batman and Gem Llama remain in the unchanged source records, with no invented variants or modified canonical sprite portraits.
- Only the draft PR and review branch are updated. The live `main` branch remains intact.
